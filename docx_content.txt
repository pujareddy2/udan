1. System Overview
Udaan AI is a 19-engine microservice-style architecture built in Python FastAPI. It helps Indian citizens discover, qualify for, and apply to government welfare schemes, scholarships, and entitlement programs. The system uses AI-driven engines to analyze user profiles and unlock value.

After login, include the JWT in every API request:
// JavaScript/Axios example
const token = localStorage.getItem('access_token');
const response = await axios.get('/api/v1/wallet/opportunities', {
  headers: { 'Authorization': `Bearer ${token}` }
});

  headers: {
    'Authorization': `Bearer ${token}`,
